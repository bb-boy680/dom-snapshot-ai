Point at any element. Tell your AI what to change.

Three steps

Set up once. Use anywhere.

01

Drag to bookmarks bar

Selector

one-time setup · ~6 KB · zero install

02

Click the bookmark on any page

A floating panel slides in. Hover any element to highlight, click to select. Works on localhost, staging URLs, React, Next.js, Vue, Svelte, and any production site.

Try it right here. Selector 已经在这个页面上运行 — hover 任意元素 → click 选中 → 右下角面板会出现 chip → 按 Copy 复制结构化 prompt。
localhost React Next.js any URL
03

Select → Copy → Paste into your AI

⌘ C copies a structured prompt — selector path, computed styles, and your written request — straight to the clipboard. Paste into Claude Code, Codex, Cursor, or any chat-based assistant.
